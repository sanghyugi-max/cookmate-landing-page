# 쿡메이트 자동직화구이기 랜딩페이지

## 1. 바로 열기

ZIP 파일을 **모두 압축 해제**하고 `index.html`을 Chrome 또는 Edge로 여세요. 설치, 빌드, 회원가입이 필요 없습니다. ZIP 내부에서 바로 열면 다른 파일이 연결되지 않을 수 있습니다.

페이지 자체는 인터넷 없이 작동합니다. 유튜브, 외부 영상·이미지, 외부 상담 링크에는 인터넷이 필요합니다. 실제 제품 사진·영상·검증된 사양·연락처는 제공되지 않아 명확한 등록 안내로 표시했습니다. 가상의 납품 사례나 성능 수치를 넣지 않았습니다.

## 2. 파일 구조

```text
cookmate/
├─ index.html       페이지 시작 파일
├─ config.js        ★ 주요 문구·영상·버튼·연락처·제품 사양 수정
├─ styles.css       색상·글자·간격·반응형 디자인
├─ script.js        설정을 화면으로 변환하고 영상을 연결
├─ assets/          직접 넣는 영상·사진·자막
│  └─ README.md
└─ README.md        이 안내서
```

## 3. 문구 수정하기

1. `config.js`를 메모장이나 코드 편집기로 여세요.
2. 원하는 항목의 **따옴표 안쪽만** 수정하세요. 쉼표, 괄호와 따옴표는 유지합니다.
3. UTF-8 형식으로 저장하고 브라우저를 새로고침하세요. 변경이 보이지 않으면 Ctrl+F5를 누르세요.

```js
title: "삼겹살, 이제 사람이\n뒤집지 마세요.",
```

`\n`은 화면에서 줄바꿈을 의미합니다. 문장 안에 큰따옴표를 넣으려면 `\"`를 사용합니다. HTML 태그는 적용되지 않고 글자로 표시됩니다. 빈 문자열 `""`은 미등록 값으로 사용할 수 있습니다.

| 수정하려는 내용 | config.js 위치 |
| --- | --- |
| 브라우저 제목·검색 설명 | `meta` |
| 브랜드·하단 문구 | `brand` |
| 첫 화면 후킹 문구·설명 | `hero` |
| 버튼 문구 | `buttons` |
| 메뉴 문구·이동 대상 | `navigation` |
| 영상·썸네일·자막 | `video` |
| 문제 제기·작동 방식·장점 | `problem`, `how`, `benefits` |
| 실제 사례·리뷰 | `cases.items` |
| Before / After | `comparison.rows` |
| 제품 사양 | `specs.rows` |
| 질문과 답변 | `faq.items` |
| 최종 상담 문구 | `cta` |
| 전화번호·상담 주소·사업자 정보 | `contact` |
| 시안 배너·등록 안내 | `draft`, `labels` |

장점, 사례, FAQ, 사양은 배열 안의 `{ ... }` 묶음을 복사해 추가하거나 삭제할 수 있습니다. 묶음 사이는 쉼표로 구분하세요. 비교표는 `["기존 방식", "변경 방식"]` 한 줄을 추가하면 됩니다.

## 4. 작동 영상 교체하기

### MP4 파일

실제 동영상을 `assets/demo.mp4`로 넣고 `video` 항목의 다음 값을 수정합니다. 나머지 안내 문구 설정은 유지하세요.

```js
type: "mp4",
src: "assets/demo.mp4",
poster: "assets/poster.jpg",
```

썸네일이 없으면 `poster: ""`로 두세요. 인터넷의 MP4 직접 주소도 사용 가능합니다. 일반적인 브라우저 호환을 위해 H.264 / AAC 형식을 권장하며 대용량 원본 대신 웹 재생용으로 압축한 영상을 사용하세요. 자동 재생은 하지 않습니다.

### 유튜브 링크

```js
type: "youtube",
src: "https://www.youtube.com/watch?v=실제영상ID",
poster: "",
```

유튜브의 공유 링크(`https://youtu.be/실제영상ID`), shorts, embed, live 주소도 지원합니다. 위 예시의 `실제영상ID`는 실제 ID로 바꿔야 합니다. 유튜브의 외부 퍼가기 허용 여부도 확인하세요. 로컬 파일로 열 때 브라우저/유튜브 정책 때문에 임베드가 거부될 수 있으므로 플레이어 아래 **유튜브에서 보기** 링크도 제공합니다. 최종 호스팅 주소에서 다시 확인하세요. 유튜브 연결 시 외부 서비스 요청이 발생합니다.

`src: ""`이면 등록 안내가 표시됩니다. MP4 경로 오류나 잘못된 유튜브 링크 형식은 오류 안내로 표시합니다. 올바른 형식이어도 삭제·비공개·퍼가기 제한 영상은 유튜브 자체 오류가 나타날 수 있습니다.

한국어 자막은 선택 항목입니다. WebVTT 파일을 넣고 `captions: "assets/captions.vtt"`로 설정하세요. 로컬 파일에서는 브라우저 보안 정책으로 자막이 제한될 수 있으므로 게시 주소에서 확인합니다.

## 5. 상담 버튼 연결하기

```js
phone: "02-1234-5678", // 설명용 예시 번호입니다. 실제 번호로 교체하세요.
url: "https://실제-상담-주소",
```

`contact.url`에 실제 상담 신청 페이지나 카카오 채널 상담 주소를 입력합니다. URL이 있으면 기본 상담 버튼은 해당 주소로 연결됩니다. 전화번호도 입력하면 최종 상담 영역에 별도 전화 버튼이 표시됩니다. URL 없이 전화만 입력하면 모든 기본 상담 버튼이 전화 연결로 작동합니다. 둘 다 비어 있으면 **상담 정보 등록 필요** 버튼으로 표시되고 연결되지 않습니다. PC 전화 연결은 운영체제의 통화 앱 설정에 따라 작동합니다.

`contact.hours`, `contact.business`도 실제 정보로 수정하세요. 이 페이지에는 정보 수집 폼이나 서버 전송 기능이 없습니다. 상담은 입력한 외부 채널 또는 전화에서 진행합니다.

## 6. 사례와 제품 정보 등록

- 사례 사진을 `assets`에 넣고 사례의 `image`에 경로를 입력합니다. `alt`에는 사진 내용을 적습니다.
- 실제 사례·후기로 교체한 항목은 `placeholder: false`로 변경합니다.
- 제품 사양의 `value`를 공식 자료로 교체하고 각각 `placeholder: false`로 변경합니다.
- 작동 흐름을 실제 모델에 맞춰 수정한 뒤 `how.placeholder`를 `false`로 변경합니다.
- FAQ의 안내용 답변을 실제 내용으로 교체한 뒤 해당 항목의 `placeholder`를 `false`로 변경합니다.
- 모든 검토가 끝난 뒤 `draft.show: false`로 변경하면 상단 시안 배너가 사라집니다. 이 설정은 다른 개별 등록 표시를 자동으로 없애지 않습니다.

## 7. 색상 및 디자인 변경

`styles.css` 첫 줄의 `:root`에서 `--accent`는 버튼과 강조 색상, `--dark`는 영상 및 상담 배경, `--ink`는 본문 글자색입니다. 외부 폰트·라이브러리를 불러오지 않으며 기기에 있는 한국어 폰트를 사용합니다. 모바일에서는 메뉴 대신 주요 상담 버튼과 하단 고정 상담 버튼을 제공합니다. FAQ는 질문을 누르면 열립니다.

## 8. 배포 전 확인

현재 결과물은 다운로드용 정적 파일이며 인터넷에 배포되지 않았습니다. 게시할 때 이 폴더의 `index.html`, `config.js`, `styles.css`, `script.js`, `assets`를 같은 상대 경로로 정적 웹호스팅에 올리세요. README는 공개 사이트에 올리지 않아도 됩니다.

- 화면 전체에서 ‘등록 필요’, ‘예시’, 대괄호 문구를 찾아 실제 자료로 교체
- 성능·효과 설명과 작동 방식이 실제 모델의 기능과 일치하는지 확인
- 사례·사진·후기의 게시 동의 및 사용 권한 확인
- 사양, 설치 조건, 가격·보증·A/S 안내 확인
- 실제 배포 주소에서 영상 재생, 전화와 상담 링크 클릭 확인
- 모바일과 PC에서 긴 문구, 사진, FAQ 표시 확인
- 공식 브랜드 표기, 사업자 정보와 필요한 고지 검토

설정 문법 오류로 화면이 나오지 않으면 마지막으로 수정한 따옴표·쉼표·괄호를 확인하세요. `config.js`를 먼저 복사해 백업해 두면 되돌리기 쉽습니다.
